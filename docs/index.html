What it does

Two-page word diff

Side-by-side word-level alignment using an LCS algorithm. Added, removed, and changed words are color-coded with hover context.

Local PDF extract

Load any PDF with selectable text and compare it like plain prose. Scanned image-only PDFs need OCR first; we tell you up front.

Synced scrolling + minimap

Both panes scroll in lockstep. A change minimap on the right lets you jump between blocks of edits at a glance.

Display modes

Switch between one-line, original-source formatting, or grouped runs. Filter the result to just added, removed, or changed words.

HTML reports

Preview a self-contained report of all additions and removals, then save it anywhere on disk. A local export log tracks recent exports.

Private by design

No analytics, no remote storage. The only network call is the optional auto-update check against GitHub Releases.

Themes & typography

Dark and light themes. Pick from system, rounded, serif, or monospaced content fonts. Zoom independently of OS scaling.

Cross-platform

Signed-friendly builds for macOS (DMG/zip), Windows (NSIS/zip), and Linux (AppImage/deb). Mobile-responsive UI for narrow viewports.
